## 2. 几何规则（所有图共用）

1. **比例尺**：`bandScale`（时间轴等距）+ `linearScale`（值→y）+ `niceTicks`（1/2/5×10ⁿ，≤3 条）。
2. **0 基线必画**：0 值画 1px 浅色基线，不再"没有柱子"。
3. **柱宽**：列宽的 62%，钳在 4–28px；列间距由剩余均分。
4. **标签抽稀**：最小间距 44px，首尾必标；时间轴按天。
5. **数值可读**：纵轴给刻度与单位；横条把值写在条尾；其余靠浮层。
6. **多系列不归一**：量纲不同的系列分面（各自独立刻度 + 单位），禁止"各自按峰值归一"并排。
7. **图体填充**：内容占图体 ≥80%，不足时居中排布，不沉底。
8. **卡片高度**：同一行等高；图体基准 132px；说明 ≤1 行、≤60 字。
9. **真实比例**：堆叠/环形/漏斗段宽 = 真实占比；小于 1% 的段在图例写「<1%」，不放大宽度。

| 接口 | 改前 p95 | 目标 p95 | 手段 |

## 5. 验收判据

1. 1440×900 与 1920×1080 截图：无标签换行/重叠，卡片同行等高，图体填充 ≥80%。
2. x 轴标签间距 ≥44px，首尾日期都可见。
3. 0 值有基线；多系列分面且标单位。
4. 生产 `/api/health/report` p95 <300ms、`/api/stats` p95 <60ms（`scripts/perf-probe.sh` 复测）。
5. 驾驶舱刷新后端请求 ≤3。
6. `make gate` 全绿；新增/修改图表有对应单测。
