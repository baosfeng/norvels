# 导入侧 P1-B：词表打标 · 单文件重试 · dry-run 预检 · 作者批量（2026-10-25）

> 前置：P1-A 已合并（迁移 0011 = books.read_status + bookmarks；importer.go 已拆分为 importer.go / epub_convert.go / wordcount.go）。
> 本批新迁移固定为 **0012**（唯一），后续批次从 0013 起。
> 侦察事实：导入只按 EPUB dc:subject 打标（book_write.go），txt 无任何关键词映射；import_errors 无 book_id / 状态；dryRun 仍建 job 并占锁、Result 无章数字数；作者批量可纯前端循环 PATCH。

## 1. 用户可见行为

- 导入页可配置**词表规则**（标签 ← 关键词列表），导入时自动给命中的书打标签；自动标签不覆盖同书的手动标签。
- 导入任务的失败清单每行可**重试**，也可一键「重试全部失败」；重试生成新任务，只跑这些文件。
- 导入页可**只预检**（dry-run）：不写库，直接给出「将导入 N 本 / 重复 M 本 / 不支持 K 个 / 解析失败 J 个」与前若干条样例；预检不建任务、不占导入锁。
- 书架可**多选**若干本书批量设置作者（含清空作者）。
- 导入任务状态 `completed_with_errors`（部分失败）不再显示成「排队中」。

## 2. 契约

### 2.1 迁移 0012

```sql
CREATE TABLE import_job_files(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  job_id INTEGER NOT NULL,
  source TEXT NOT NULL,
  display_path TEXT NOT NULL,
  status TEXT NOT NULL,
  reason TEXT NOT NULL DEFAULT "",
  book_id INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX ux_import_job_files ON import_job_files(job_id, source);
ALTER TABLE book_tags ADD COLUMN source TEXT NOT NULL DEFAULT "";
```

- `source` = **可重放源**：目录文件用绝对路径；zip 条目用 `<zip 绝对路径>:<包内路径>`（沿用 zip.go 现有 candidate 形态）；合集拆分段沿用其伪路径。`display_path` 只用于展示。
- `status` 取值：`imported` / `failed` / `skipped` / `unsupported` / `canceled`。
- `book_tags.source`：空字符串（手动 / 历史）/ `auto`（词表命中）/ `epub`（dc:subject）。存量行保持空字符串，不回填。

### 2.2 API

| 端点 | 契约 |
|---|---|
| `GET /api/settings/tag-rules` | `{"rules":[{"tag":"奇幻","keywords":["魔法","精灵"]}]}`，无配置返回 `{"rules":[]}` |
| `PUT /api/settings/tag-rules` | 全量替换，成功 204；条数 >50、标签名空或超 20 字、单条关键词 0 或 >100 个、单词 >20 字 → 400 `invalid_param`；同名标签出现两次 400 |
| `GET /api/import/jobs/{id}/files?status=failed` | `{"files":[{"id":1,"source":"…","displayPath":"…","status":"failed","reason":"…","bookId":0,"updatedAt":"…"}]}`；不带 status 返回全部（最多 1000 条，超出 `truncated:true`） |
| `POST /api/import/jobs/{id}/retry` | body `{"sources":["…"]}` 省略则重试该任务全部 `failed`；202 `{"jobId":<新任务 id>}`；任务不存在 404；任务仍在 running 409 `conflict`；没有可重试项 400 `invalid_param`；源不在该任务 400 |
| `POST /api/import` `{dryRun:true}` | **不建任务、不占锁**，同步返回报告（结构见 2.3）；目录条目 >200 时只解析前 200 并置 `truncated:true`；单次请求最长 60 秒，超时 503 `timeout`；非 dryRun 行为与返回不变 |
| `GET /api/import/jobs/{id}` | 增 `failedCount`（= `failed` 状态的 import_job_files 条数），其余字段不变 |

- 重试生成**新任务**（复用现有 job 状态机），不改原任务记录；新任务的 `import_job_files` 只含本次重试的文件。
- 词表打标在导入时执行：命中即写标签（source=`auto`），只增不删；同书已有同名标签（任意 source）不重复插入，且不改变其 source；与 EPUB dc:subject 标签去重后保留源标签。

### 2.3 dry-run 报告结构（importer.Report）

```json
{
  "truncated": false,
  "files": {"total": 12, "willImport": 9, "duplicate": 2, "unsupported": 1, "failed": 0},
  "books": {"new": 8, "duplicate": 2, "split": 1},
  "sample": [{"source":"/path/to/txt","title":"示例书名","chapters":12,"words":34567,"duplicate":false,"reason":""}],
  "errors": [{"source":"/path/to/x.pdf","reason":"unsupported_format"}]
}
```

- `sample` 最多 20 条（按扫描顺序）；`errors` 最多 50 条。
- 判定口径与真实导入一致：同一 SHA-256 或书名 + 作者指纹命中即 `duplicate`；扩展名不支持即 `unsupported`；解析出 0 章记 `failed`。

### 2.4 词表匹配口径

- 匹配文本 = 书名 + 作者 + 前 3 章标题 + 正文前 5000 字（去空白后小写比较）。
- 关键词为子串包含匹配（大小写不敏感），不做正则、不做分词。
- 单书命中上限 10 个标签；同一标签命中多个关键词只打一次。
- 规则顺序 = 用户保存顺序，不影响结果（取并集）。

### 2.5 前端（web/src）

- 导入页：①「只预检」按钮 + 报告面板（四类计数 + 样例表 + 错误清单）；②任务失败清单来自 `/files?status=failed`，每行「重试」+ 顶部「重试全部失败」；③状态标签补 `completed_with_errors` → 「完成（部分失败）」。
- 词表规则编辑：设置区可增删规则（标签名 + 关键词逗号分隔）、保存后即时生效提示；未配置词表时不显示额外 UI。
- 书架：进入多选模式（长按或右上角「选择」），选中 N 本后「批量设作者」对话框，确认后循环 `PATCH /api/books/{id}`（`authors` 字段），实时进度「已完成 x / N」，失败项列出并支持重试；批量操作不发新后端请求类型。
- **口径覆盖**：`authors` 传空数组 = 清空作者，允许并生效（覆盖 P0 契约里「authors 空数组 400」的旧口径）；清空后详情 `authors` 返回空数组，`author` 回落到空串。
- 四态齐全；触摸目标 ≥44×44；不新增长驻条。

## 3. 工程化决定

| 能力 | 决定 | 程度 | 依据 |
|---|---|---|---|
| 词表打标 | 做 | settings KV + 导入时匹配 + 只增不删 | 复用 settings 与现有标签写入通道，零新概念 |
| 单文件重试 | 做 | 迁移 0012 记录 per-file 终态 + 新任务重跑 | 失败只能整批重来，对 800 本库代价高 |
| dry-run | 做 | 同步、不建任务、≤200 文件 | 预检的价值是导入前知道会怎样，落库反而污染任务列表 |
| 作者批量 | 做，纯前端 | 循环 PATCH，实时进度 | 单用户库规模小；新增批量端点无第二个调用方 |
| 后台任务队列 / 断点续跑 | 省 | 不做 | 单进程单用户，重试已覆盖主要场景 |

## 4. 验收

- `make gate` 9 项全绿，覆盖率不低于基线（store 83.1 / api 82.8 / parser 88.5 / importer 90.0）。
- 词表：PUT 两条规则 → GET 回显；非法（51 条 / 空标签 / 关键词超限）→ 400；导入含关键词的合成 txt → 该书带 auto 标签；再导入同书 → 标签不重复；手动标签不被覆盖。
- 重试：导入含 3 个坏文件的目录 → 任务 `completed_with_errors`、`GET /files?status=failed` 返回 3 条；`POST /retry` 202 → 新任务只处理这 3 个；原任务记录不变；对已结束任务重试正常，对 running 任务 409。
- dry-run：`{dryRun:true}` 返回 2.3 结构，计数与随后真实导入一致（差异仅 `truncated`），且**不新增 import_jobs 行**、不阻塞并发的真实导入。
- 作者批量：前端选中 3 本 → 循环 PATCH 3 次，书架与详情作者更新；清空作者后 `authors` 为空数组。
- 前端：导入页可看到预检面板与重试按钮；`completed_with_errors` 显示「完成（部分失败）」（vitest 断言）。
