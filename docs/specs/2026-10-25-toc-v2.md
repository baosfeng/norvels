## 2. 冻结契约（共享层已由 leader 落地，不得改签名）

### 2.1 `web/src/lib/tocRows.ts`（纯函数，已带单测）

```ts
buildTocRows(chapters, columns): TocRow[]        // 视觉行：一行 N 章，行内按章序
rowIndexOfChapter(chapters, columns, id): number // 当前章所在行，-1 表示没有
columnsForWidth(width): 1 | 2 | 3                // ≥1180 三列 / ≥900 两列 / 其余一列
filterChapters(chapters, query): ChapterBrief[]  // 目录搜索：标题（不分大小写）或章号
```

### 2.2 `ChapterList` 属性（`features/book/ChapterList.tsx`）

| 属性 | 语义 |
|---|---|
| `columns?: number` | 视觉列数，默认 1；PC 用 `columnsForWidth(window.innerWidth)` 算 |
| `dense?: boolean` | 32px 紧凑行高（PC 鼠标）；默认 44px 触控行高 |
| `fill?: boolean` | 高度撑满父容器（抽屉里用），忽略 `maxHeight` |
| `scrollToCurrent?: boolean` | 首次渲染后把当前章滚到中间 |
| `maxHeight?: number` | 不给且 `fill=false` = 不限制高度（详情页整页滚动） |

行内结构不变：`.cv-row` > `.cv-title`（1fr 省略）+ `.cv-word`（定宽右对齐，`data-testid="chapter-word"`）。

### 2.3 CSS（`styles/prototype.css`，leader 已改）

- `.vol-virtual` 不再写死高度；`.vol-virtual.is-fill{height:100%;max-height:none}`
- `.cv-grid{display:grid}`：一行 N 格，列宽 `repeat(N, minmax(0,1fr))` 由内联样式给，列间距 20px

## 4. 验收（每路都要给出实测）

- A：单卷书不渲染 `.vol-jump` 与 `.vol-head`；多卷书照常；1280 宽 `data-columns=3`、行高 32px、
  一屏容量 ≥45 章；390 宽 `data-columns=1`、行高 44px；横向溢出 0。
- B：抽屉里 `[data-testid=chapter-scroll]` 类含 `is-fill` 且高度 = 抽屉可用高度（无 340px 死区）；
  搜索框输入章号只剩命中行；「跳到当前章」把当前章滚进视口；打开抽屉即定位到当前章。
