# P3 范围与验收（阅读体验 / 发现 / 管理补全）

> 只实现下列 11 项，其它一律不做（见「明确不做」）。契约见 [p3-contract](2026-10-25-p3-contract.md)、[p3-store-api](2026-10-25-p3-store-api.md)。

## 要做（11 项）

1. **阅读排版细节**：字体族（衬线/黑体/系统）、段距、页宽、对齐（左/两端）、简繁（繁→简）、跟随系统深色、字号跟随系统。
2. **进度与追更**：章内段落位置记忆（进入章节滚回原段，离开时上报）；追更新章数（导入 `--update` 追加时累计）+ 书架/详情角标，读完最后一章清零。
3. **筛选与发现**：评分（0–5 星）、自定义书单（扁平收藏夹）、书架「继续阅读」入口、随机一本。
4. **可访问性/移动端**：抽屉与弹窗焦点陷阱；H5 顶栏视图切换按钮失效修复；字号随系统；键盘可达。
5. **自动滚动/自动翻页**：速度 1–5 档、暂停/继续、到底自动翻章（可选）、失焦暂停。
6. **键盘补全**：`PageUp`/`Shift+Space` 上翻、`?` 快捷键帮助面板；**删除正文末尾那行快捷键提示**。
7. **系列聚合页**：`/series` 列表（书数/字数/最近更新/封面）+ `/series/:name` 详情。
8. **阅读时长统计/热力图**：按日聚合秒数、今日/本周/累计、近 90 天日历热力、连续天数。
9. **阅读历史**：分页历史页（书/最后章节/最后阅读时间/累计时长）。
10. **管理侧补全**：标签 CRUD（新建/改名/删除）；书籍 PATCH 补 `publisher/pubDate/isbn/language`；新建章节（含插入位置）；批量改书籍（单接口）；二级作者进入作者页/筛选/统计。
11. **B 类缺陷（5 条）**：阅读器 toast 不可见；导入进度不轮询；搜索命中无上下文（snippet 恒空）；H5 视图切换无效；书签抽屉「正在保存…」写死。

## 明确不做（本轮）

笔记/划线/摘录导出、TTS 听书、正文全文检索、单本导出、OPDS、PWA、多用户、i18n、评论评分社区、运营动作。

## 取舍（已定，不再讨论）

- **简繁只做繁→简单向**，内置常用字对照表（≤3000 条，gzip 后 <15 KB）；简→繁一繁多字、质量不可控，不做。
- **书单是扁平收藏夹**（一本书可属多个书单），不做嵌套、共享、排序。
- **VACUUM / 备份不进 HTTP**：会长时间锁库且已有 `scripts/backup.sh`；本轮不提供运维端点。
- **阅读时长前端聚合上报**：页面可见时累计，≥60 s 且（切换章节/隐藏/卸载）才 POST 一次，避免轮询写放大。
- **新建章节只支持「插到指定章之后」或「追加到末尾」**，不支持跨卷任意位置。
- 评分 0 星 = 未评，不参与 `rating` 筛选与 `sort=rating`。
