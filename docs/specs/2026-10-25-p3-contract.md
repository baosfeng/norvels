# P3 契约：数据与接口

> 范围见 [p3-scope](2026-10-25-p3-scope.md)。Go 侧函数签名见 [p3-store-api](2026-10-25-p3-store-api.md)。
> 字段名即 JSON 名（camelCase）；时间统一 UTC ISO-8601 文本；错误码沿用 `codeInvalidParam` 家族。

## 迁移 0014（只加列/加表，不搬数据）

```sql
-- Go step（幂等）：books.rating INTEGER NOT NULL DEFAULT 0
--             books.new_chapters INTEGER NOT NULL DEFAULT 0
--             books.last_chapter_at TEXT NOT NULL DEFAULT ''
--             reading_progress.para_index INTEGER NOT NULL DEFAULT 0

CREATE TABLE IF NOT EXISTS reading_sessions (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    book_id    INTEGER NOT NULL,
    chapter_id INTEGER NOT NULL,
    started_at TEXT    NOT NULL,
    seconds    INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX IF NOT EXISTS ix_sessions_started ON reading_sessions(started_at DESC, id DESC);
CREATE INDEX IF NOT EXISTS ix_sessions_book    ON reading_sessions(book_id, started_at DESC);

CREATE TABLE IF NOT EXISTS collections (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    name       TEXT    NOT NULL UNIQUE,
    created_at TEXT    NOT NULL
);
CREATE TABLE IF NOT EXISTS collection_books (
    collection_id INTEGER NOT NULL REFERENCES collections(id) ON DELETE CASCADE,
    book_id       INTEGER NOT NULL,
    added_at      TEXT    NOT NULL,
    PRIMARY KEY (collection_id, book_id)
);
```

- `reading_sessions` 与 `collection_books` 不声明 books 外键：删书由 `internal/store/delete.go` 的级联清单显式清理（新增两行）。
- `new_chapters` 只由追更链路写；`ack` 接口清零。存量行保持 0，不回填、不猜。

## 前端契约

- `web/src/api/types.ts`：新增 `Collection`、`SeriesSummary`、`ReadingStats`、`ReadingHistoryRow`、`TagSummary`；`Bookmark` 不变。
- `web/src/api/client.ts`：以上端点一一对应方法，错误走既有 `ApiError`。
- 路由：`/series`、`/series/:name`、`/history`（PC 专属，H5 隐藏靠 `TierRoute`）；侧栏加入口。
- 阅读设置新增键（localStorage）：`norvels.reader.fontFamily|para|width|align|script|autoScroll`；主题增 `system` 档。
- 新增纯逻辑模块（必须可单测）：`lib/trad2simp.ts`、`lib/autoScroll.ts`、`lib/readingTimer.ts`、`lib/focusTrap.ts`、`lib/seriesGroup.ts`。
