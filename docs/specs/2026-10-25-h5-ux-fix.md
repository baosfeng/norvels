# H5 触摸体验修复：返回定位 · 长标题溢出 · 触摸细节（2026-10-25）

> 来源：用户实机反馈（P1-A 之后）。根因已由只读侦察实测确认（/tmp/h5-ux-recon.md），不是猜测。
> 本批纯前端（web/src），不动后端、不加迁移。
> 不在本批：段级续读（需要 ReadingProgress 增加段落下标的后端契约，另批）。

## 1. 用户可见行为

- 从阅读器返回书架，回到**原来的滚动位置**与已加载的列表，不再重新从第 1 页开始。
- 返回书架时自动把**最近在读**的那本书滚到视口并高亮 1.5 秒。
- 长书名在任意屏宽**不横向溢出**；H5 书架卡片书名最多 3 行后省略，作者最多 2 行。
- 阅读状态角标不再压住书名文字。
- 长按书架/目录条目不会选中文字。
- 阅读器控制层新增「书架」出口，直接回书架并恢复位置（不再必须先回详情页）。

## 2. 契约

### 2.1 书架状态保持

- 书架列表状态（items、下一页页码、滚动位置、当前筛选与排序）写入 sessionStorage，键 norvels.shelf.v1；写入时机 = 滚动停止 300ms 防抖、加载完成、筛选/排序变化。
- 进入书架时若存在该键且 **不超过 30 分钟**，先用缓存渲染（不闪白屏），再后台刷新第 1 页并与缓存合并（按 book id 去重，保留已加载数量）。
- 恢复后恢复 scrollTop（误差 ≤ 100px）。数据版本变化（接口返回 total 变化 > 0）时仍保留列表，不强制回顶。
- 清空缓存的唯一出口：手动刷新页面（F5）或缓存超时。

### 2.2 返回语义

- 卡片进入详情/阅读器时带 location state `{ from: "shelf", scrollTop }`；详情页与阅读器的「返回」优先 `navigate(-1)`，无历史时回落 `/shelf`。
- 阅读器控制层加入口「书架」（图标文字均可），点击直接 `navigate("/shelf", { state: { restore: true } })`。
- 浏览器的后退按钮行为与之一致（不得把 /read 作为唯一历史项）。

### 2.3 长标题与布局

- 移除 `.book-main h1 / .page-head h1 / .dir-head h2` 的 `white-space: nowrap`（prototype.css:575-578），改为 `overflow-wrap: anywhere`；详情页书名默认最多 3 行。
- 书架卡片：书名 `.book-title`（或 h3）`-webkit-line-clamp: 3`、`display: -webkit-box`；作者 `.book-author` 2 行截断。
- H5（≤520px）书架改为**单列**；521–768px 允许双列但卡片书名区可见宽度 ≥ 160px，否则也单列。
- 阅读状态角标不覆盖书名：H5 放在卡片底部独立一行（与章节数同行右侧），不再绝对定位压 h3。

### 2.4 触摸细节

- 书架条目、目录条目、书签条目：`user-select: none`、`-webkit-touch-callout: none`、`-webkit-tap-highlight-color: transparent`。
- `.page-head .sub` 的 nowrap 在所有断点收敛（≤768 允许换行）。

## 3. 验收（全部用 agent-browser 实测，430×900 与 1280×900 两个视口）

- 滚动加载到 60 本 → 进书 → 返回：scrollY 与离开时差 ≤ 100px；期间网络请求**不含** `GET /api/books?page=1`（缓存命中）；列表项数 ≥ 60。
- 自动定位：返回后最近在读那本书的 `getBoundingClientRect().top` 在视口内（0–844）。
- 33 字书名：`document.documentElement.scrollWidth === clientWidth`（无横向溢出）；详情 h1 高度 ≥ 56px（至少两行）。
- 书架卡片标题 `-webkit-line-clamp` 生效（高度 = 3 行），作者 ≤ 2 行；角标与标题 `getBoundingClientRect()` 不相交。
- 长按书架条目 1000ms：`window.getSelection().toString() === ""`。
- 阅读器「书架」出口：点击后 URL 为 /shelf 且 scrollY 恢复。
- `pnpm test` 全绿（新增用例覆盖缓存恢复、返回语义、角标不重叠）+ `pnpm build` exit 0。

## 4. 工程化决定

| 决定 | 程度 | 依据 |
|---|---|---|
| 用 sessionStorage 而非全局 Context | 只存书架列表状态，30 分钟过期 | 刷新页面也要保持；Context 在刷新后丢失 |
| 缓存先渲染再刷新 | 首屏用缓存，后台合并 | 避免返回时白屏与跳动 |
| 段级续读 | 不做 | 需要后端 ReadingProgress 增段落下标，另批 |
| 新增「书架」出口 | 做 | 现在从阅读器只能回详情页，多两步 |
