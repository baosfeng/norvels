# 阅读器：不横滑换章 · 全屏与分页的底部留白（2026-11-22）

> 来源：用户实机反馈两条，均经 390×844 实测复现。
> 纯前端（web/src），不动后端、不加迁移。分页几何仍按 [h5-paged-reading](2026-11-04-h5-paged-reading.md)。

## 1 用户可见行为

| 场景 | 行为 |
|---|---|
| 滚动模式左右滑 | 只滚动，不换章；换章走三区单击 / 键盘 / 进度滑块 |
| 分页模式左右拖 | 仍是一页一页翻（翻页引擎接管，不经过换章） |
| 分页模式底部 | 页高拿满视口，不再常留 40px（恢复胶囊在场时 96px）空白带 |
| 进入全屏 | 立即收起控制栏；底栏 / 顶栏是浮层，不推正文、不留空白带 |
| 全屏 + 唤出控制栏 | 正文位置与页高不变，控制栏浮在正文之上 |
| 翻页收尾 | 动画帧被系统暂停 / transitionend 丢失时按理论时长兜底落定，之后照常翻页 |

## 2 契约

### 2.1 滚动模式不再横滑换章

- `useSwipePaging` / `useReaderSwipe` 整条移除；正文层不再挂 touchstart / touchmove / touchend。
- 保留的换章入口：左 / 右三成单击、键盘 ←/→、底栏与滑块的章按钮、书签与目录跳转。
- 分页模式的横向手势归 `PageTurnEngine`（pointer 事件 + `touch-action: pan-y`），与本次移除无关。
- 帮助面板与读屏提示同步删掉「左右滑动」条目，避免写了但没实现。

### 2.2 分页与全屏不留底部留白带（H5 ≤768px）

- 外壳 `.reader-shell` 的 `padding-bottom` 只保留 `env(safe-area-inset-bottom)`（文字不被手势条遮住）。
- 例外判据写在 CSS：`:has(.reader-paged)`（分页）与 `.is-fullscreen`（真全屏 / 页面内全屏）。
  滚动模式的 40 / 96 / 56 / 125px 让位规则原样保留（见 [h5-ux-round2](2026-10-31-h5-ux-round2.md) §2.2）。
- 分页 / 全屏下 `.reader-main` 不再 `translateY(64px)`、不再补 `padding-bottom`：控制栏是覆盖层。
  两条规则必须写在 `.is-controls .reader-main` **之后**——同特异性靠顺序取胜。
- 页高 = 舞台高向下取整到行高整数倍，余量上下均分（`padY`）；分页舞台上只剩这段 ≤ 半个行高的排版余量。

### 2.3 进入全屏即收起控制栏

- `useReaderFullscreen` 的两条路径（浏览器 Fullscreen API / 页面内全屏）都调 `onEnter`，
  由页面接成 `controls.hide()`；退出全屏不重复调用。
- 全屏时控制栏仍可单击中区唤出，浮在正文上，3 秒自动收起。

### 2.4 翻页收尾兜底

- `PageTurnEngine.run` 在 `settle` 之后挂 `duration + 240ms` 的看门狗：到点强制落定（提交页码 / 回弹）。
- 理由：`fade` / `curl` 的收尾靠 `requestAnimationFrame` 逐帧推进，`slide` / `cover` 靠 `transitionend`；
  后台标签页暂停 rAF、重排丢掉 transitionend 都会让 `done` 永不到达，`busy` 永远为真——
  表现是「之后每次点击 / 滑动都翻不动页」。
- 兜底用 `active` 标记保证只落定一次；`cancelSettle` 在 `land` 之前置空，避免递归。

## 4 工程化决定

| 决定 | 依据 |
|---|---|
| 不横滑换章，而不是加开关 | 读者往下滚时横向漂移 40–70px 很常见，误触一次就丢位置；点按已有三区，不缺入口 |
| 分页 / 全屏用覆盖式控制栏 | 让位式（正文下移 + 底部留白）在任何一屏都表现为「不是真全屏 + 底下一条空白」 |
| 判据落在 CSS `:has()` 而不是再加一个 React 类 | 分页与否已经由 `.reader-paged` 表达，多一个状态位就是第二份真值 |
| 兜底放在引擎而不是每个效果里 | 五种效果共用同一套收尾协议，兜底只有一处才不会漏 |
| 安全区仍保留 | 页高拿满不等于让文字被 iPhone 手势条压住 |
| 页首锚点用「列号 + 列内顶端」判定 | 同列内所有段的 left 相同，只看 left 会取到本页最后一小段——字号一变，读者滑走大半页 |

## 5 已知限制

- 全屏 / 分页下唤出控制栏时，顶栏与底栏覆盖正文（分页约 3 行、滚动最后 1–2 行）；收起后即恢复。
- 分页页码浮标（「第 p / P 页」）浮在页底最后一行上方，停手 1.2 秒淡出——不再有专属留白带放它。
- 进章时的恢复提示胶囊同理浮在页底，3 秒自动消失。
- `prefers-reduced-motion` 下兜底时长仍是 `duration + 240ms`（duration 已为 0，等同一个 240ms 的保险）。
