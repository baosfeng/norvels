## 语义约束

- `PatchBooksBatch` 与单本 PATCH 共用 `BookMetaPatch` 与校验，错误文案一致。
- `ListSeries` 只统计 `TRIM(series) <> ''`；排序按 `lastUpdatedAt DESC`。
- `ReadingStats.Streak` = 从今天往前连续有会话的天数（今天无会话而昨天有 → 0）。
- `ReadingHistory` 按书聚合：`lastReadAt = MAX(started_at)`，`totalSeconds = SUM(seconds)`，`days = COUNT(DISTINCT date)`。
- `InsertChapter` 与 `DeleteChapter` 后都要重排 `idx` 并更新 `books.chapter_count/word_count`。
