# 阅读体验 P1：阅读状态 · 书签 · 章节内搜索 · 编码（2026-10-25）

> 来源：P1 复核清单（main@d9d6ff8，门禁基线全绿）。本批只做阅读侧四件事 + importer 拆分；元数据与导入侧（词表自动打标、作者批量补录、单文件重试、dry-run 报告）另批，契约不得提前占用。
> 侦察事实：tags/book_tags 与标签 UI 已存在（本批不动）；正文到前端已是整章字符串，章节内搜索不需要后端；importer.go 396/400 行，先拆分再做导入侧改动。

## 1. 用户可见行为

- 书架可按**阅读状态**筛选：全部 / 想读 / 在读 / 已读；书卡显示状态角标，点击循环切换。
- 详情页可设置阅读状态；读到某处后状态自动从空变为「在读」。
- 阅读器可在当前位置**加书签**；书签抽屉列出全书书签（章节名 + 段落首句），可跳转、可删除；同一位置重复添加不产生重复条目。
- 阅读器可**搜索本章**：关键词高亮、显示「第 n / N 处」、上一个 / 下一个跳转。
- 编码检测支持 Shift-JIS（日文）与 Big5-HKSCS（繁中），不再把这两类文件当 GB18030 / UTF-8 乱码入库。

## 2. 契约

### 2.1 迁移 0011（本批唯一新增迁移；后续批次从 0012 起）

```sql
ALTER TABLE books ADD COLUMN read_status TEXT NOT NULL DEFAULT '';
CREATE TABLE bookmarks(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id INTEGER NOT NULL,
  chapter_id INTEGER NOT NULL,
  chapter_idx INTEGER NOT NULL,
  para_index INTEGER NOT NULL,
  label TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL
);
CREATE UNIQUE INDEX ux_bookmarks_pos ON bookmarks(book_id, chapter_id, para_index);
CREATE INDEX ix_bookmarks_book ON bookmarks(book_id, created_at DESC);
```

`read_status` 取值：`''`（未标记）/ `want` / `reading` / `done`。存量行保持 `''`，不回填、不猜测。
`bookmarks` 不声明外键，删除书籍/章节时由 `DELETE /api/books/{id}` 的级联语句显式清理（与现有 7 张子表一致）。

### 2.2 API

| 端点 | 契约 |
|---|---|
| `PATCH /api/books/{id}` | 新增 `readStatus`，白名单 `''`/`want`/`reading`/`done`，其它 400 `invalid_param`；可与 `serialStatus` 同批出现 |
| `GET /api/books/{id}` | 新增 `readStatus`、`bookmarkCount` |
| `GET /api/books?readStatus=want` | 新增筛选参数，非法值 400；与 sort / author / tag 可组合 |
| `GET /api/books/{id}/bookmarks` | `{"bookmarks":[{"id":1,"chapterId":9,"chapterIdx":4,"chapterTitle":"…","paraIndex":12,"label":"…","createdAt":"…"}]}`，按 created_at 倒序 |
| `POST /api/books/{id}/bookmarks` | body `{chapterId, paraIndex, label?}`；chapterId 不属于该书 400；paraIndex < 0 400；同一 (chapterId, paraIndex) 已存在 → 200 并更新 label（幂等，不重复插入）；新建 201 |
| `DELETE /api/bookmarks/{id}` | 204；不存在 404 |
| `PUT /api/books/{id}/progress` | 语义增：写入时若 `read_status = ''` 则同事务置 `reading`；不覆盖 `want` / `done` |

- 级联删除：`DELETE /api/books/{id}` 的删除语句列表加入 `bookmarks`，`bookmarkCount` 随之归零。
- 新端点沿用现有错误体 `{"error":{"code":"…","message":"…"}}` 与 `invalid_param` / `not_found` / `conflict` 口径。

### 2.3 前端（web/src）

- 类型：`Book.readStatus`、`Book.bookmarkCount`、`Bookmark`、`BookListQuery.readStatus`。
- 书架：筛选加阅读状态（全部/想读/在读/已读；H5 收进弹层）；书卡角标点击循环 want → reading → done → 空。
- 详情页：元信息区加状态下拉（未标记/想读/在读/已读），PATCH 后即时回显。
- 阅读器：控制层加「书签」「搜索」两个入口；书签抽屉与目录抽屉同级、互斥打开；搜索面板贴正文顶部，Esc 或关闭按钮退出并清除高亮。
- 书签定位：正文按 `\n` 切段后的段落下标，与后端 `paraIndex` 一致；label 默认取该段前 30 字（去空白），可编辑、可留空。
- 章节内搜索：纯前端。以段落为单位匹配，大小写不敏感，单章最多高亮 200 处（超出提示「仅显示前 200 处」）；无匹配显示「无匹配」；不新增请求。
- 四态齐全（加载/空/错误/有数据）；点击目标 ≥44×44；沿用现有 dvh / 安全区 / 控制层收起逻辑，不新增长驻条。

### 2.4 编码（internal/parser）

- 新增 `EncShiftJIS`、`EncBig5HKSCS` 常量与 codec，注册进现有探测顺序；分数不足时保持回退 UTF-8 + 乱码可见，不猜。
- 顺序保证：Shift-JIS 样本不得判为 GB18030，Big5-HKSCS 样本不得判为 GB18030 / UTF-8；用**虚构**日文/繁中样本断言，不得引用真实语料。
- 仍不做繁简互转。

### 2.5 importer 拆分（技术债，零逻辑变更）

- `internal/importer/importer.go`（396 行）拆出：epub 转换簇（约 243–350 行）→ `epub_convert.go`；字数统计簇（约 351–390 行）→ `wordcount.go`。
- 同包导出符号与行为零变化；拆分后 `scripts/gate-size.sh` 通过。

## 3. 工程化决定

| 能力 | 决定 | 程度 | 依据 |
|---|---|---|---|
| 阅读状态 | 做 | 独立列 + 三态 + 手动切换；仅自动 `''`→`reading` | 与解析态 status、连载态 serial_status 互不覆盖 |
| 书签 | 做 | 段落级 + 幂等 upsert | 无账号体系；段落比字符偏移更耐正文重排 |
| 章节内搜索 | 做，纯前端 | 整章内存匹配，上限 200 处 | 正文已在前端；后端搜正文要解压 1MB 块，且 FTS 已按 ADR-0002 删除 |
| 编码扩展 | 做 | 只补两个常见东亚编码，失败保持原样 | 港台/日文资源常见，误判入库比不支持更糟 |
| 已读自动判定 | 省 | 只允许手动设 | 自动阈值会误标，可预期性差 |
| FTS5 正文索引 | 省 | 不做 | ADR-0002 已删，库体积与隐私口径不接受 |

## 4. 验收

- `make gate` 9 项全绿，覆盖率不低于基线（store 83.1 / api 81.9 / parser 88.2 / importer 89.9）。
- 阅读状态：PATCH `readStatus=reading` → GET 详情 `reading`；传 `abc` → 400；`GET /api/books?readStatus=done` 只返回 done。
- 自动转在读：新书 `''` 时 PUT 进度 → 详情 `reading`；`want` 时 PUT 进度 → 仍 `want`。
- 书签：同 (chapterId, paraIndex) POST 两次 → 总数 1 且第二次 200；列表按时间倒序；DELETE 后同 id 404；删书后 `bookmarkCount` 为 0。
- 搜索：vitest 断言 5 段文本关键词 3 处 → 显示「1 / 3」，下一个到「2 / 3」；无匹配显示「无匹配」。
- 编码：Shift-JIS 与 Big5-HKSCS 虚构样本各 1 例检测正确并解出原文；现有 UTF-8 / UTF-16 / GB18030 / Big5 用例全绿。
- 拆分：`scripts/gate-size.sh` 通过；`go test ./internal/importer/ -count=1` 全绿；`git diff --name-only` 仅 importer 包内文件。
