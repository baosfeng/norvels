# 书籍分类（0015）

分类是「来源目录」的投影：两级、可空、字符串，不是独立实体，也不与标签混用。

| 字段 | 含义 |
|---|---|
| `categoryL1` | 大分类（如 `玄幻`） |
| `categoryL2` | 小分类（如 `东方玄幻`）；空串 = 该大分类下未细分 |

## 写入口径

- **导入时自动推断**：文件相对导入根的**前两级目录**即 `(l1, l2)`；纯数字前缀剥掉（`01玄幻` → `玄幻`）；下划线开头的目录（`_待删除_*`）与不足两级的路径落空分类。zip 条目按**包路径**推断（不是临时解包路径）；分卷合并成一本时取首卷的分类。
- **手工修正**：`PATCH /api/books/{id}` 带 `categoryL1`/`categoryL2`，给出即全量写入（TRIM + 截断 40 字符），传 `""` 即清空。大分类清空不连带清空小分类。
- **存量回填**：加列的那一刻，库里已有的书统一记为部署方指定的分类
  （环境变量 `NORVELS_LEGACY_CATEGORY`，缺省 `未分类`）——它们没有来源目录可推断。
  迁移重放（删版本号重跑）不会再覆盖后来导入的书。

## GET /api/categories

返回两级分类树与各自书数，供书架筛选器与分类页使用；按 `(l1, l2)` 字典序稳定排序。

```json
{ "items": [
    { "l1": "历史", "count": 1, "items": [ { "l2": "两宋元明", "count": 1 } ] },
    { "l1": "玄幻", "count": 4, "items": [ { "l2": "东方玄幻", "count": 3 }, { "l2": "奇幻玄幻", "count": 1 } ] }
  ], "total": 5 }
```

- `l1` 为空串的节点是「未分类」（直接放在导入根下的书），前端展示为「未分类」；
- `items[].l2` 为空串表示该大分类下有未细分的书。

## 筛选口径

`GET /api/books?categoryL1=玄幻` 返回该大分类下的全部书；再加 `categoryL2=东方玄幻` 精确到小分类。只给 `categoryL2` 时按**不过滤**处理（前端不会造出这种组合）。

> 空串已经被「不过滤」占用，所以**不存在**「只筛未分类」的查询参数——未分类的书只在「全部分类」里出现。
