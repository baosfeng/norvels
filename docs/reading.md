# 阅读体验（reading）

> 阅读器**现在有什么、边界在哪、怎么验收**——现状只在这里查，设计记录与取舍理由留在下方的设计文档里。
> 本文只写读者从界面上读不到的判断；能一眼看到的行为不进正文。

## 能力一览

| 能力 | 读者能看到什么 | 边界 |
|---|---|---|
| 目录与连续流 | 卷分组目录、章名搜索；滚过章末自动接下一章 | 窗口固定 5 槽（同屏约 3–5 章）；目录搜索只匹配章名/章号，不搜正文 |
| H5 分页与翻页效果 | 手机默认左右翻页，五种效果：滑动/覆盖/淡入淡出/仿真折页/无动画；拖动跟手、松手提交或回弹；左 30% / 中 40% / 右 30% 单击翻页 | 只在 ≤768px 挂载；折痕竖直；三区比例不可配置；减少动态效果时全部退化为无动画 |
| 自动滚动 / 自动翻页 | 滚动模式匀速下滚；分页模式每页停留若干秒自动翻页 | 同一个速度档在分页下映射为 3.5–14 秒/页；章末是否续读由独立开关决定 |
| 排版与主题 | 字号 5 档、行距 1.4–2.4、段距 4 档、对齐 2 档、首行缩进、字体族 4 种、繁转简；主题 7 档 | 页宽只对 PC 生效；字号吸附 5 档没有连续滑杆；繁转简单向逐字查表 |
| 书签 | 段落级书签，抽屉内跳转与删除，可导出 Markdown / JSON | 同一位置幂等不重复；标签取该段前 30 字且无编辑入口；只导出当前这本 |
| 章内搜索 | 关键词高亮、「第 n / N 处」、上一个/下一个；分页下定位到命中页 | 纯前端只在当前章内匹配；单章上限 200 处，超出只提示 |
| 进度与恢复 | 段级记忆：再进这本书回到上次那一章的那一段 | 后端每本书只留一条最后位置；回看别的章一律落章首 |
| 阅读状态与统计 | 想读/在读/已读；今日时长、连续天数、热力图 | 状态在书架与详情页改，阅读器内无入口；只有「未标记 → 在读」一条自动流转 |
| 朗读 | 播放/暂停/停止、0.5–2.0 倍速、引擎与音色选择、章末自动翻章 | 系统语音零依赖；段落级高亮不是句级；分页模式下没有段落高亮 |
| AI 辅读 | 本章摘要、解释选中段、本章问答（任意 OpenAI 兼容接口） | 正文截 16000 字；配置存本地；无流式、无历史、无取消 |
| 离线 | 装成 PWA 后断网仍能打开最近读过的章节 | 只缓存最近 24 个章节接口响应，目录与书架不在离线范围 |
| 全屏与无障碍 | 一键全屏、控制栏浮层 3 秒自动收起；面板焦点陷阱、控制层 inert、快捷键帮助 | iOS 上降级为页面内全屏；分页正文对读屏按页整段朗读，不能逐句停留 |

## 读者能感知的契约

- **PC 恒为连续滚动**：分页与翻页效果只在 H5（≤768px）挂载，判定只有 `readerPageMode.ts` 一处；手机上选的分页方式在 PC 上不生效但值保留，回到手机仍是那一套。
- **位置真值是「章 + 段」，不是滚动像素**：后端每本书只存一条最后位置，所以从第 12 章回看第 3 章会落在章首——这是当前口径，不是偶发。
- **分页模式下正文不可选词**（`user-select: none`）：横向拖动翻页优先于选词；要复制或选中去问 AI，切到「上下滚动」。
- **主题存浏览器本地，排版设置按账号同步**：换设备后字号/行距跟着走，背景色要重选（代码只有排版字段过服务端；spec 写的是「主题也同步」，以代码为准）。
- **朗读优先系统语音、零新增依赖**：外部 HTTP 引擎按协议（POST `{ text, rate, voice }` → 音频）预留，引擎下拉目前只列系统语音。
- **阅读时长每段 ≥60 秒才计入**：不足阈值的停留直接丢弃；长读每 5 分钟兜底落一次库，进程被杀也不至于全丢。
- **分页页高按行高取整、余量上下均分**：视口高向下取整到整行，剩下不到一行的高度平分到上下（具体像素以 spec 实测为准）。

## 验收入口

| 项 | 口径 |
|---|---|
| 命令 | `make audit-reader`（前置 `scripts/preview.sh --detach`） |
| 环境 | 真 Chrome + 本机书库，默认 390×844；换机加 `--viewport=320x640` |
| 断言 | 18 条读者可感知的不变量：舞台 = 视口、页高对齐行高、全屏收起控制栏、五种效果连翻三页、章末跨章、横滑不换章等 |
| 结果 | 条件不成立记「跳过」并打印原因，失败打印实测值与期望；当前基线：18 通过 · 0 跳过 · 0 失败 |
| 何时跑 | 改阅读器布局 / 手势 / 全屏前先跑；不进 `make gate`（CI 没有 Chrome 与本机书库） |

## 已知限制

- 分页没有划线、高亮、笔记能力：正文只渲染纯文本加搜索高亮，全库也没有批注表。
- 章内搜索单章上限 200 处，长章里的高频字很容易触顶，页码显示的是截断后的数量。
- 朗读是段落粒度：中文长段里看不出念到第几句，分页模式下连段落高亮都没有。
- 离线只覆盖最近 24 个章节响应，断网进目录或书架会落到离线兜底文案。
- 全屏在 iOS 上降级为页面内全屏：控制栏覆盖正文，正文位置不变。
