## 5 破坏性操作一览（全部二次确认）
| 操作 | 确认方式 | 默认焦点 | 可撤销 |
|---|---|---|---|
| 删除本书 | 抄写书名一致才解锁按钮 | 取消 | 不可撤销 |
| 批量删除书籍 | 弹层写明本数、正文/封面/进度一起删 | 取消 | 不可撤销；失败项可重试 |
| 批量改标签 | 不弹确认（与源码一致） | — | 旧标签被整体替换、不可恢复；操作条已写明「会替换」 |
| 删除单章 / 删除所选章节 | 写明书名、章号区间、总字数 | 取消 | 不可撤销；后续章号自动补上 |
| 删除卷 | 写明卷内 N 章会回到「未分卷」 | 取消 | 卷本身不可撤销；章节正文都还在 |
| 删除标签 | 写明会从 N 本书解绑、书不受影响 | 取消 | 不能恢复，书本身不受影响 |
| 取消导入任务 | 写明已入库的书保留、进行中的文件不入库 | 继续跑 | 可重新开一次任务 |

## 6 与源码的差异清单（开发照此表排除原型的加分项）
| 对象 | 源码现状 | 原型建议 | 本轮处置 |
|---|---|---|---|
| 大分类 / 小分类 / 作者三个筛选 | 分类字段与分类聚合端点都已存在，但列表筛选只有关键词 / 标签 / 连载状态 | 筛选条加三个下拉，大小分类联动 | 按原型冻结为「新增」，**本轮不实现**；需列表支持按分类筛选，另开任务 |
| 封面「移除」 | 单击即移除，即时生效 | 原型加了二次确认 | 降级为建议，**按源码即时生效**；封面可随时再传，加确认反而挡路 |
| 批量改作者 / 标签 / 连载状态 | 不弹二次确认，一次提交；单本失败不整体回滚 | 不弹确认，结果里给成功 / 失败本数与逐条重试 | 与源码一致，保留 |
> 判据：只有不可撤销且代价高的操作才二次确认（删书 / 删章 / 删卷 / 删标签 / 批量删除）。
