## 分档口径（与源码一致，不自创）

- H5 = 视口 ≤768。管理类入口（书籍管理 / 驾驶舱 / 作者 / 导入管理）与发现域三页（系列 / 系列详情 / 阅读历史）在 H5 **不出现**，直接落到首页；不是样式隐藏。
- 书架两档保留同一份数据集合：PC 用分页（每页 24）与筛选工具条；H5 用无限滚动（每页 30）+ 排序底部弹层，卡片收成单列简表（去掉简介、评分星标与随机一本）。
- 触控目标 H5 ≥44×44，PC 可点区 ≥32×32；键盘 Tab 可达、焦点环用 `--focus-ring`；Esc 关闭抽屉与弹层。
- 空态与错误态一律用同一套三态面板，不另造样式；失败都要给出下一步（重试 / 清除筛选 / 去导入）。
