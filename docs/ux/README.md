# 交互设计文档（UX Spec）· 规范与索引

> 本文冻结**交付形态与验收口径**；具体页面的交互设计在 `docs/ux/<域>.md`。
> 开发按「文档 + 原型」对照实现，不做自由发挥；原型是几何与交互的唯一基线。

## 1. 三件套（缺一不算交付）

| 产物 | 位置 | 作用 |
|---|---|---|
| 交互设计文档 | `docs/ux/<域>.md` | 写清每个元素的触发/结果/状态/撤销，是开发与评审的判据 |
| 交互原型 | `.open-design/ux/<域>.html` | 单文件自包含，可点、可切状态、可切断点；几何基线 |
| 截图 | `.open-design/ux/shots/<域>-<断点>.jpg` | 1440 与 390 各一张，取证用（jpg q80，≤600KB） |

文档每份 ≤120 行；一份装不下按 `<域>-<子页>.md` 拆，索引登记在本文第 7 节。

## 2. 交互描述口径（文档表格列，缺列视为未写）

| 列 | 必填内容 |
|---|---|
| 元素 | 页面 + 可读名称 + 原型锚点 `data-od-id` + 源码位置 |
| 触发 | 单击 / 双击 / 长按 / 悬停 / 滑动 / 滚轮 / 键盘键 / 拖拽 —— 逐个写，不合并 |
| 结果 | 发生什么（跳转 / 就地变化 / 弹层 / 请求） |
| 状态 | 默认 / 悬停 / 聚焦 / 按下 / 选中 / 禁用 / 加载中 / 空 / 错误 |
| 撤销 | 如何反悔（再次点击、Esc、撤销条、二次确认、不可撤销时明说） |
| 分档 | PC / H5 的差异（形态、入口、是否渲染） |
| 标签 | `现有` / `改进` / `新增` —— 三者必须能区分 |

必写完整的情形：**长按与双击的替代路径**（触屏无悬停）、**破坏性操作的确认与撤销**、
**禁用态为何禁用**、**失败后用户下一步做什么**。

## 3. 分档规则（与实现一致，不得自创）

- 断点：PC ≥1024 全功能工作台；H5 ≤768 轻量阅读器；`useTier()` 的 `H5_QUERY = (max-width: 768px)`。
- H5 下管理类入口（导入 / 作者 / 驾驶舱 / 书籍管理）**不渲染**，不是 CSS 隐藏。**「不出现」= 该入口在窄屏不存在，不是藏起来**——文档与原型统一用「出现 / 不出现」表述，不用「渲染 / 挂载」这类实现词。
- 阅读器两端能力等价，只换入口形态（目录全屏抽屉、设置底部面板）。
- 触控目标 H5 ≥44×44；PC 可点区域 ≥32×32；键盘 Tab 可达且焦点环可见（`--focus-ring`）。

## 4. 原型要求

1. 单文件自包含：CSS 内联、不引 CDN、不引外链字体与图片。
2. 颜色只用 `--*` token（`.open-design/02-style.md` 的 warm-editorial 56 槽，逐字复制），不出现裸色值。
   代码侧另有 4 个 `color-mix` 派生色（`--success-text` / `--warn-text` / `--danger-text` / `--scrim`，见 `web/src/styles/tokens.css`），原型与代码保持一致即可，**不回写 02-style.md**。
3. 每个可交互块带 `data-od-id="<域>:<元素>"`，命名与文档表格一一对应。
4. 演示控制条：切页面 / 切状态（加载·空·错误·正常）/ 切断点。**只在原型里存在**，统一带 `demo:` 前缀，产品不得带入。
5. 交互要真的能动：点开抽屉、提交校验、切主题、翻章、切筛选都要能演示，不做静态图。
6. 断点至少 1440 与 390 两档可切，禁止横向溢出。
7. **跨档共用的渲染函数写 DOM 一律走判空助手**：分档是把节点真的移出文档（不是 CSS 隐藏），共用的渲染函数若直接给窄屏不存在的控件赋值会抛错误、中断后续逻辑（症状：点了有反应但弹层不关、列表不变）。
8. **状态切换要对每一页都有效**：切「加载中 / 错误」时该页必须真的出现对应面板，不允许只有部分页面挂了状态容器。

## 5. 自检命令（作者交证据，跑不通不算交付）

```bash
odops verify .open-design/ux/<域>.html --platform web --browser   # 期望 exit 0
odops shot .open-design/ux/<域>.html --width 1440 --out .open-design/ux/shots/<域>-1440.jpg
odops shot .open-design/ux/<域>.html --width 390  --out .open-design/ux/shots/<域>-390.jpg
grep -o 'data-od-id' .open-design/ux/<域>.html | sort -u | wc -l   # 唯一锚点数，报给 leader
```

## 6. 冻结的评审清单（评审 agent 逐条判，P0 一条不过即返工）

| # | 级别 | 判据（可核验） |
|---|---|---|
| 1 | P0 | 页面里每个可交互元素都在文档出现，且有标签（现有/改进/新增） |
| 2 | P0 | 每个元素写全：触发方式、结果、失败或不可用时的表现 |
| 3 | P0 | 原型能打开、主流程点得通、状态可切（**每一页都能切**）、1440 与 390 均无横向溢出 |
| 4 | P0 | 相关状态齐全：加载 / 空 / 错误 / 禁用 / 选中，缺一扣一 |
| 5 | P0 | 文档写的每条交互在原型里能找到对应 `data-od-id` 并演示（文档↔原型双向对表，差集为空） |
| 6 | P0 | 无实现词外露：SQLite / FTS / API / bookId / localStorage / 虚拟滚动 / SHA-256 / 用时 / 端点 / 后端 |
| 7 | P0 | 无真实书名、作者、本机路径；示例一律虚构 |
| 8 | P0 | 触控目标 H5 ≥44×44、PC ≥32×32、键盘可达、焦点环可见 |
| 9 | P1 | 悬停/聚焦/按下/禁用/选中 五态对**按钮类**元素有定义（纯展示行标「—」可不写） |
| 10 | P1 | 破坏性操作有二次确认或明说不可恢复，并写进破坏性一览表 |
| 11 | P1 | 手势有非手势替代路径，且不与浏览器默认行为冲突（滚动/返回/下拉刷新） |
| 12 | P1 | 空态给出下一步动作，无死胡同；错误提示可重试 |

**覆盖度口径**：判据 1 与 5 的实际判法是「**文档元素行数 ≥ 原型唯一 `data-od-id` 数，且双向差集为空**」。
不拿源码 `data-testid` 计数对比——它含测试钩子与重复项（每行操作按钮共用一个前缀），口径不可比。

**分级**：P0 = 阻塞交付（打不开 / 主流程走不通 / 文档原型对不上 / 状态缺失 / 外露实现词 / 真实书名 / 触屏目标不达标）；
P1 = 随交付记待办（五态不全 / 撤销描述笼统 / 手势无替代路径）；P2 写进报告不进修复轮。

## 8. 术语

- **控制层**：阅读器顶部/底部按钮条，H5 默认收起，单击正文唤出，3 秒无操作收起。
- **抽屉 / 面板 / 弹层**：`drawer` 从侧边滑出；`panel` 贴边浮层；`sheet` 移动端底部弹层；`dialog` 居中模态。
- **空态 / 错误态**：`components/StatePanel.tsx` 的三态面板（加载 / 空 / 错误），不得另造样式。
- **锚点**：原型里的 `data-od-id`，文档表格与原型唯一的对表键。
