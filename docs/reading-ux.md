# 阅读体验打磨（reading-ux）

> 只写**现有能力的摩擦点与量化判据**，不写新功能提案。阅读器现状与边界见 [reading](reading.md)，分页几何真值见 [h5-paged-reading](specs/2026-11-04-h5-paged-reading.md)。
> 实测环境：真 Chrome + 本机书库，390×844 为主、1280×800 补测；数字取 5 次中位。复跑方法见 §5。

## 1 基线（0.13.5 实测）

| 指标 | 390×844 | 1280×800 | 判定 |
|---|---|---|---|
| 首屏正文可见 | 长章 249 ms · 短章 196 ms | 209 ms | 好 |
| 翻一页（松手→新页） | slide 305 · cover 318 · fade 235 · curl 417 · none 20 ms | — | curl 偏慢 |
| 1 秒连点 5 次 | 只前进 **2** 页 | — | 差 |
| 跨章翻页（章末→下章首页） | **52 ms**，比同章快 255 ms（不播动画） | — | 好 |
| 滚动滚过章末 | 空白帧 0（157 帧采样最少 16 行） | 空白帧 0 | 好 |
| 改字号 20→28 重排 | 223 ms，同段保持（段顶偏移 48 px 内） | 180–345 ms，可见段漂移 **−154~−189 段** | PC 差 |
| 切模式（分页↔滚动） | 85 / 65 ms，**位置不保持**（第 3 页→章首→第 0 页） | 无切换 | 一般 |
| 目录打开（4413 章） | 46 ms 可滚，首屏 60 行 | 36 ms | 好 |
| 改行距 3 档的完整路径 | 5 次点击 / 1.55 s | 4 次 / 1.03 s | 一般 |
| 控制栏自动收起 | 3015–3019 ms（设定 3000） | 常显 | 好 |

## 2 摩擦点（按读者当场「咦」一下的强度排序）

## 3 修的顺序

先修**输入丢失与位置丢失**（U1 / U2 / U3）——这三条是「读着读着被打断」，代价最高；再修**遮挡与闪烁**（U4 / U5 / U6 / U7），它们让读者怀疑自己看错了；最后是**可发现性与多余步骤**（U9 / U12–U17）。

每条修完必须落一个判据进 `make audit-reader`（真浏览器）或前端 vitest；只改不看 = 没修。

## 4 不在这份清单里的

新增能力（划线、笔记、跨章检索、字典、竖排双列、X-Ray、阅读目标）**不在排期**：读者要的是「现在这套用起来顺手」，不是更多入口。

## 5 复跑

scripts/preview.sh --detach    # 后端 :8080 + vite :5173
