# 交互契约 · 书目域（`/book/:bookId` · `/authors` · `/dashboard`）

> 规范：`designing-interactions`（`SKILL.md` + `references/interaction-contract.md`）。项目口径见 [../README.md](../README.md)。
> 一行 = 一个控件的一种触发；同一控件的 click / hover / focus / 键盘 共用同一 `C-nn` 锚点。
> 原型：[02-prototype.html](02-prototype.html)（锚点逐字相同）。示例书名作者均虚构。
> 平台 = web；H5 ≤768 / PC ≥1024（`web/src/lib/tier.ts:9`）。控件名后缀「仅 PC」表示窄屏下该节点不出现（`TierRoute`，不是 CSS 隐藏）。
> 列约定：`反馈` 列未写文案原文即表示文案不变；`移除/关闭后` 列写「—」表示该触发不改变焦点与列表归属。

## 0. 本域边界（先读，避免按细节猜）

- **删除本书**：详情页不提供删除入口。删除只在书籍管理页 `/admin/books/:id` 的确认弹层里，需把书名一字不差抄进输入框才可执行，不可恢复（`BookPage.tsx:152` 注释 · `DeleteBookConfirm.tsx:8`）。
- **评分清零**：点第 n 颗打 n 分；再点当前那一颗则清零回到未评分（`RatingStars.tsx:36`）。
- **作者页搜索**：本域不加搜索框，保持现状只有排序 + 分页；全文搜索留作后续需求（`AuthorsPage.tsx:26` 只有排序）。
- **单卷书**：`volumeCount=0`（只有「未分卷」伪卷）时不渲染卷跳转与卷头，章节直接铺开（`BookToc.tsx:105`）。
- **追更角标**：只在打开全书最后一章时清零；清零失败只浮提示条，不阻断阅读（`newChapters.ts:27`）。
- **窄屏缺失能力**：作者页与驾驶舱在 H5 下整页不渲染，`/book` 保留但转单列（`tier.ts:16` · `TierRoute.tsx:18`）。
