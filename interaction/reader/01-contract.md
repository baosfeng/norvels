## 覆盖计数

- 控件 **58** 个，契约行 **236** 行；每个控件都含 click 或 输入 一种主动激活触发。
- 桌面端 focus 覆盖 **58/58**——每个可点控件都有 focus 行，写明 focus-visible 焦点环。
- hover 覆盖 **58/58**。
- 按下态：全部 click 行均写明「按下 100ms 内」的视觉反馈。
- **新增能力 3 个**：C-16 / C-27 / C-29。其中 C-16 进度恢复提示条是评审 P0-4 的整改结论——产品当前无此交互，整组标新增。
- 四态锚点：加载 = C-14 / C-35 的 loading 反馈、**目录加载态（C-06 抽屉打开时）**；空 = C-15（正文空）、C-31（目录无匹配）、书签空态（C-32 前置）；错误 = C-14（正文失败）、C-35（书签失败）；成功 = C-16 / C-32 / C-34 等的浮条提示与自动消失时长。
- 手势替代：C-10 左右滑动翻章 ↔ C-11 / C-12 / C-17 / C-23 按钮 ↔ 键盘 ← →，四条路径在各自 `边界` 列互相点名。
- 删除走二次确认、**不做撤销**：C-34 点删除 → C-58 弹出确认框 → C-59 取消 / C-60 确认删除；确认后不可恢复。不做撤销条的理由：改造全站提示条代价高于重加一条书签。

## 双档行为差异（列表，不是表格）

- **控制层**：PC 恒显示；H5 默认收起，C-09 单击唤出、3s 无操作自动收起、再点立即收起。
- **顶栏内容**：PC = 返回 / 书名章进度 / 书架·书签·搜索·目录·帮助·设置（C-03…C-08）；H5 = 返回 / 书名章进度 / 全屏（C-02）。
