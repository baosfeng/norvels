# 发现域（discovery）交互契约

> 范围：外壳（侧栏 · 顶栏 · 抽屉 · 提示条 · 404）· `/home` · `/shelf` · `/search` · `/series` · `/series/:name` · `/history`。
> 一行 = 一个控件的一种触发；锚点 `C-nn` 与 [02-prototype.html](02-prototype.html) 的 `data-od-id` 逐字相同，一经发布不改号。
> 规范见 `designing-interactions`（`SKILL.md` + `references/interaction-contract.md`）；项目口径见 [../README.md](../README.md)。
> 平台 = web；H5 ≤768px / PC ≥1024px（`web/src/lib/tier.ts:9`）。`控件` 列末尾是源码证据（`文件:行号`，逐条 `grep -n` 核对过）；标「仅 PC」「仅 H5」的控件在另一档**不出现**（`TierRoute.tsx:18`，不是 CSS 隐藏）。
> 示例书名作者全部虚构。

## 0 本域已冻结的口径（先读，避免按细节猜）

- **评分只在书籍详情页给**：书架书卡只显示阅读状态角标，不给星标（`ShelfPage.tsx:679` 只有 `book-status` 一个可点区；评分控件在 `RatingStars.tsx:52`，属书目域）。
- **检索范围只有书名、作者、章节标题**：正文不参与检索，因此结果不显示正文片段，**也不做关键词加粗**（`SearchPage.tsx` 全文 `<b>/<strong>/highlight` 命中 0；产品不做正文检索是既有决策）。
- **错档落点**：窄屏访问管理类页面 → 落 **`/home`**；宽屏访问首页 → 落 `/shelf`（`TierRoute.tsx:18-22`）。落点是重定向，不是把那一页画出来。
- **搜索分页是新增能力**：服务端已支持 `page` / `size`（`web/src/api/client.ts:236`），前端现已接入分页（每页 8 条，`SearchPage.tsx:224`），C-54 / C-55 的边界列写明两栏一起翻页。
- **表格列约定**：`移除/关闭后` 列写「—」表示该触发不改变列表归属、焦点位置与计数；`反馈` 列只写与默认态不同的部分，未写文案原文即表示文案不变。
- **书架排序**：改排序 / 改筛选一律回第 1 页并滚到顶部；排序为「评分」时只排已评分的书。
- **提示条不可交互**：`layouts/ToastHost.tsx:26` 是 `role="status" aria-live="polite"` 的只读浮层，没有可聚焦元素，因此只有 1 行契约。
