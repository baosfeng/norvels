# 发现域（discovery）交互契约

> 范围：外壳（侧栏 · 顶栏 · 抽屉 · 提示条 · 404）· `/home` · `/shelf` · `/search` · `/series` · `/series/:name` · `/history`。
> 一行 = 一个控件的一种触发；锚点 `C-nn` 与 [02-prototype.html](02-prototype.html) 的 `data-od-id` 逐字相同，一经发布不改号。
> 规范见 `designing-interactions`（`SKILL.md` + `references/interaction-contract.md`）；项目口径见 [../README.md](../README.md)。
> 平台 = web；H5 ≤768px / PC ≥1024px（`web/src/lib/tier.ts:9`）。`控件` 列末尾是源码证据（`文件:行号`，逐条 `grep -n` 核对过）；标「仅 PC」「仅 H5」的控件在另一档**不出现**（`TierRoute` + `tier.ts` 的路由档位表，不是 CSS 隐藏）。
> 示例书名作者全部虚构。

## 0 本域已冻结的口径（先读，避免按细节猜）

- **评分只在书籍详情页给**：书架书卡只显示阅读状态角标，不给星标（`ShelfPage.tsx:679` 只有 `book-status` 一个可点区；评分控件在 `RatingStars.tsx:52`，属书目域）。
- **检索范围只有书名和作者**：章节标题与正文都不参与检索（接口恒传 `type=book`，`SearchPage.tsx:29`），因此结果只有「书名和作者」一栏、没有 tab、不显示片段、**也不做关键词加粗**。
- **错档落点**：窄屏访问管理类页面 → 落 **`/home`**；宽屏访问首页 → 落 `/shelf`（`TierRoute.tsx:18-22`）。落点是重定向，不是把那一页画出来。
- **搜索分页是新增能力**：服务端已支持 `page` / `size`（`web/src/api/client.ts:236`），前端现已接入分页（每页 8 条，`SearchPage.tsx:224`），C-54 / C-55 是唯一的分页入口（结果只有一栏）。
- **表格列约定**：`移除/关闭后` 列写「—」表示该触发不改变列表归属、焦点位置与计数；`反馈` 列只写与默认态不同的部分，未写文案原文即表示文案不变。
- **书架筛选两档同一套**：PC 用页头下方的常驻工具栏，H5 收进底部弹层（排序 + 阅读状态 / 评分 / 分类两级 / 作者 / 书单 / 标签 + 清除筛选）。分类选项两档同源（`GET /api/categories`），筛选值都走 `useBookFeed` 的同一组查询参数。
- **筛选状态进地址**：`?sort=` `?author=` `?tag=` `?status=` `?rating=` `?collection=` `?l1=` `?l2=`（默认值不写）。刷新、后退、把链接发给别人都能复现同一屏；会话缓存只兜底列表、页码与滚动位置。
- **书架排序**：改排序 / 改筛选一律回第 1 页并滚到顶部；排序为「评分」时只排已评分的书。
- **系列与阅读历史两档都开**：`/series`、`/series/:name`、`/history` 不再被 `TierRoute` 挡住；阅读历史 PC 用表格、H5 用卡片列表，分页两档都对。删除两档同一套：H5 卡片右上 ✕、PC 表格「操作」列 ✕，点开都就地换成「确认删除 / 取消」二段式；只清阅读会话，**进度与书签保留**（不级联）。
- **错档只发生在管理四页与首页**：`web/src/lib/tier.ts` 的 `PC_ONLY_ROUTES` / `H5_ONLY_ROUTES` 是唯一事实源，`routes.tsx` 只把一级段名交给 `TierRoute` 查表，两边不会各写一套。
- **提示条不可交互**：`layouts/ToastHost.tsx:26` 是 `role="status" aria-live="polite"` 的只读浮层，没有可聚焦元素，因此只有 1 行契约。
