# norvels 发版说明

> 面向使用者：每个版本新增了什么、改进了什么、修好了什么，以及升级时要注意什么。
> 产品里的「更新日志」页（`/changelog`）读的就是这份文件——它用 go:embed 打进二进制，
> 仓库与产品不会各有一份。新版本在最上面。
>
> 写法：`## [x.y.z] - YYYY-MM-DD` + `### 新增 / 改进 / 修复 / 升级注意`，条目按用户视角一句话，
> 不写提交号、内部文件名与实现细节。发版前必须在这里补一节（见 [docs/release.md](../docs/release.md) §5）。
> 早期版本的发版说明是事后从 git 历史回溯整理的，版本标题末尾标「（据 git 历史回溯）」。
>
> 升级前先备份（`scripts/backup.sh --keep 7`）；数据库只会向前迁移，回滚要把备份一起恢复。

## [0.12.1] - 2026-11-07

### 改进

- **驾驶舱健康卡从「永远超时」变成秒开**：0.12.0 已把 `/api/health/report` 从 21 秒降到 1.5 秒级，
  这一版把最后三条「每次请求都把同一批页重读一遍」的统计（缺简介 / 缺作者 / 章节数分桶）改成
  0025 预计算，由写路径上的触发器维持；17 万本规模下这三项现在各是微秒级读取。
  降级路径仍在：未迁移或回填未完成时回退实时 SQL，数字正确、不返回错误。

### 升级注意

- 本版有数据库结构变化（0025 新增三张健康计数表、一个生成列与七条触发器）。**迁移只建结构**，
  存量书的三项计数在启动后由后台任务回填（books 一遍扫描，完成前健康报告走实时 SQL）。
- 触发器让每本新书入库时多 3~5 次单行更新；169,230 本量级可忽略。

## [0.12.0] - 2026-11-07

### 新增

- **接口性能可以从页面看了**：驾驶舱新增「接口耗时」区块，按路由列出次数、平均、p50/p95/p99 与错误数，
  并保留最近 20 条慢请求（含可复现的完整路径与 request id）；数据来自新增的 `GET /api/metrics`。
- **慢 SQL 单独可查**：SQL 按归一化模板聚合（次数 / 平均 / p95 / 慢查询次数），用来区分
  「接口慢」是库慢还是程序慢；同时记录 goroutine 数、堆占用、GC 次数与两个连接池的排队情况。
- **命令行探针**：`scripts/perf-probe.sh` 对同一部署逐个打关键接口，输出首次 / 平均 / 最慢 / p95，
  `--json` 可直接对比升级前后。

### 改进

- **驾驶舱健康卡不再超时**：17 万本 / 5125 万章的库上，`GET /api/health/report` 从 21 秒（并发下更久）
  降到亚秒级。原因是两处「每次请求都全表扫」被移出请求路径：指纹覆盖率改为读书级覆盖表
  （5125 万行 COUNT(DISTINCT) 变成 17 万行 COUNT），正文对账改为后台快照、请求只读结果并标 stale。
- **列表页、搜索、随机一本、统计变快**：书目查询补了部分索引（标题排序不再落临时 B-TREE、
  计数走覆盖索引），列表 total 在无关键词时不再多 JOIN 一次作者表，随机一本改为 id 采样而不是
  随机 OFFSET 扫半张表。17 万本规模下：标题排序 308→4 ms、随机一本 558→1 ms、列表 134→4 ms、
  统计 127→13 ms、搜索 206→115 ms。

### 升级注意

- 本版有数据库结构变化（0023 新增书级指纹覆盖表、0024 新增书目查询索引）。**0023 只建表，
  历史指纹回填在启动后后台分批进行**，不阻塞服务、可中断续跑，进度看日志或
  `GET /api/health/report` 的 `fingerprints.backfilling`。
- 升级完成后建议对主库与正文库各跑一次 VACUUM（正文库会多出约 2–3 MB 的覆盖表）。

## [0.11.1] - 2026-11-06

### 修复

- **文件名开头的来源标记被当成了书名**：形如「【某来源】真正的书名.txt」的文件，以前整批书都会显示成那个标记名
  （同一来源的书全叫一个名字），现在取标记之后的主体作书名；标记后面带「作者：xxx」的也一并正确。
- **这类书的存量书名已一并改正**：库里受影响的 1,580 本已按新规则重命名，搜索与书架显示随之恢复。

### 升级注意

- 本版没有数据库结构变化，直接更新镜像即可。

## [0.11.0] - 2026-11-06

### 新增

- **手机阅读器改成左右翻页**：手机上默认按页阅读，左右滑动、点两侧或按 ←/→ 翻页，底部浮标显示
  「第 p / P 页」；章末继续往后翻直接进下一章，章首往回翻落到上一章最后一页，跨章不会白屏或闪回。
- **五种翻页效果**：滑动（默认）/ 覆盖 / 淡入淡出 / 仿真折页 / 无动画，在阅读设置里切换，下一次翻页生效。
- **分页下的键盘与读屏**：←/→ 翻页、Home/End 首末页、空格与 PageDown 也能翻页；读屏只念当前页的段落，
  不再整章念一遍。

### 改进

- **自动滚动在分页下变成自动翻页**：每页停留设定秒数再翻一页，浮条写「自动翻页中」。
- **驾驶舱打开就有数**：趋势、章节长度分布、作者榜这些聚合改为事先算好，不再每次现场统计整个库。
- **PC 阅读器保持原样**：宽屏仍是上下连续滚动，两个分页相关设置在电脑上置灰并注明「手机专用」。
- **NAS 升级默认不备份**：`update.sh` 升级不再成对备份数据库（需要时加 `--backup`）；任何一步失败仍会
  自动把镜像版本回滚到升级前。
- **依赖与构建工具链更新**：Go 1.27、Node 26、Vite 8、Vitest 5、ESLint 10 等升到当前稳定版。

### 升级注意

- 本版有一项数据库升级（驾驶舱预计算）：启动时自动建汇总表并回填，实测十几秒；期间驾驶舱相关接口
  返回「尚未就绪」的标记而不是报错，升级完即可正常使用，**不需要**手动跑任何回填命令。
- 升级前建议照例备份数据库（`scripts/backup.sh --keep 7`）——本版之后 `update.sh` 默认不再自动备份。

## [0.10.0] - 2026-11-04

### 改进

- **阅读器翻章有了翻页转场**：上一章 / 下一章（键盘左右键、三区点按、目录跳转）现在是旧页滑出、新页滑入，
  反向连点方向正确，转场也不再闪白。
- **手机打开目录直接就是书的目录**：不再一进去就弹出输入法；顶部搜索收成一个「搜索章节」入口，点了才展开，
  取消后回到列表。
- **推荐卡改横向列表**：发现页的书卡一行一本，封面缩小、右侧信息更全（分类、字数、章数），手机上一屏能看到更多本。
- **侧栏账号区压成一行**：账号菜单改为向上弹出，不再在侧栏里占掉一截。
- **更新日志页重排**：左侧版本目录（手机上是顶部横滑），右侧单列版本卡片；条目里的粗体、代码与链接按 Markdown
  正常显示，不再是字面的星号。入口从主导航移到页脚的版本位——想确认这版改了什么，点版本号进去。
- **删除账号**只保留在登录页的账号列表里，侧栏不再放这个不常用的操作。

### 修复

- **PC 端左右键翻上一章 / 下一章落位过冲**：以前顶栏章号、正文与「已翻到第 N 章」会互相对不上，连按还累积偏移；
  现在每次都精确落在目标章开头。
- **连续滚动跨章不再「往上顶」**：翻章后章节判定不会退回翻章前那一章。
- **翻章时下一章还没到货**不再把整条阅读流清空，停留在原处等正文到达。
- **「上次读到」提示 3 秒后真的会消失**，不再必须点「知道了」；自动收起时也不会把焦点从正文里拽走。
- **点作者昵称**：进入「全部书」并按该作者筛选，不再是空的「我的书架」，筛选条上能看到作者名并能取消。
- **搜索页标题字号**与全站页头一致，原来比别的页大了一截。
- **推荐块只有两三条时**不再撑成半屏巨卡（书架底部、详情页「你可能也喜欢」）；首页窄屏推荐位改成 3 列，
  一屏能看全 6 本。

### 升级注意

- 本版没有数据库结构变化：直接更新镜像即可，无需额外的迁移或回填步骤。

## [0.9.0] - 2026-11-02

### 新增

- **手机阅读器连续翻章**：往下翻到本章末尾会接着显示下一章，继续读不用回目录；往上翻到顶则回到上一章的最后一屏，
  中途正常滚动不会误切章节。
- **一首输入走到底的账号入口**：只填账号名、只点一次「进入」——名字没建过就顺手建好，建过就直接进。
- **删除账号**：在侧栏账号区可以删除当前账号，它的书架与阅读记录一并清除；内置默认账号不可删除。
- **更新日志页**（本页）：应用内就能看到每个版本改了什么，不用去 GitHub。
- **场景推荐位**：首页、书架、搜索无结果时给出「接下来读什么」，并标明这一块是按什么推的。

### 改进

- 手机端书架的筛选条件直接铺在列表上方，不再藏在底部抽屉里；分组标题常驻、每项带数量、
  已选条件可单独取消，「清除筛选」常驻，底部常显结果数。
- 详情页手机端的底部预留高度按实测吸底栏收窄，末行正文不再被多余空白顶开。
- 上一章 / 下一章按钮点下去真的会加载：换章后停在章首，加载失败就地给出重试。

### 修复

- 登录之后账号列表与侧栏仍显示「从未登录」：登录时没有记录活跃时间，现在进入即更新，
  当前账号显示真实的「上次活跃」。

### 升级注意

- 本版起，发版流程把「更新本文件」列为打 tag 前的必做项，tag 说明取自对应版本条目；
  前端门禁也会校验当前版本号在本文里有条目，漏写直接判红。
- 历史版本的发版说明是按 git 历史回溯整理的，跟实际发布不完全一一对应，仅供了解演进。

## [0.8.0] - 2026-11-01 （据 git 历史回溯）

### 新增

- 多账号与「我的书架」：每个账号的书架、阅读进度与历史互相独立。
- 手机（H5）主流程补齐：书架、详情、阅读器、搜索、阅读历史、账号在手机上都能走通。
- 可插拔书源导入：支持粘贴 Legado 书源，统一按净化规则处理。
- 书单独立成页，成员管理不再藏在书架工具栏里。
- 阅读历史支持删除单条与清空。
- 章末显示「约几分钟」与「还剩约几小时」，长书也知道什么时候收尾。
- 健康明细可下钻：从驾驶舱健康卡直接看到具体是哪些书、哪些章节。
- 导入判重与版本择优：同一本书重复导入时按内容指纹判重，质量更高的版本可被选为保留版本。
- 导入升级的替换走人工审核（可选配 AI 辅助裁决），不会自动替换已有书籍。

### 改进

- 正文改用内置字码本 + zstd 压缩，单块 8 MB：库体积明显下降，读路径仍是纯 Go。
- 正文独立成库（与元数据分开），备份与迁移更可控。
- 阅读器：章末无缝接下一章、阅读态常驻进度条与滚动浮层、目录当前章高亮与定位更准。
- 手机阅读器：三区手势、进度滑条、字号五档、背景六档，目录与书签合并成一个抽屉。
- 手机书架改为三列封面网格，更新角标与阅读进度口径统一。
- 搜索：筛选平铺且渐进展开，点一下即搜；补搜索历史与命中高亮。
- 详情页与管理页排版压缩，正文页头更省屏。

### 升级注意

- 首次启动会自动迁移数据库（多账号、正文重新压缩、正文拆到独立文件、内容指纹与质量分），
  大库耗时可达十几分钟以上，**迁移期间服务不监听端口**；升级前务必先备份。
- 迁移不缩小文件体积，升级完成后建议跑一次 VACUUM（NAS 上用更新脚本的整理子命令）。
- AI 辅助审核需要单独配置 key；不配置时该能力等同不存在，导入与管理照常。

- NAS 更新脚本：升级前自动备份、失败自动回滚、支持一键升级到最新版。
- 书籍管理：删除书籍、连载状态、最新章节、取消导入、多卷归并、自定义切章规则。

### 改进

- 自定义切章规则同时作用于「目录导入」与「上传导入」两个入口。
- 保存章节规则的接口统一返回「已保存」语义，与进度接口一致。

### 修复

- 取消导入时两条处理管线都真正停下，任务标记为已取消。

## [0.3.0] - 2026-10-25 （据 git 历史回溯）

### 新增

- 浏览器上传导入，支持 EPUB（含封面与元数据编辑）。
- ZIP 批量导入、合集拆分、追更增量导入、多作者。

### 改进

- 手机书架无限滚动 + 排序底部弹层。
- 阅读器控制层单击唤出、顶部与底栏整体自动显隐、全屏与触摸适配。

### 修复

- 阅读器控制层滑出屏幕把文档撑高。

### 升级注意

- 首次启动会自动迁移数据库（多作者与导入相关结构），升级前先备份。
- EPUB 需先去除 DRM；加密的书会被拒绝入库，不会写进半个文件。

## [0.2.0] - 2026-10-25 （据 git 历史回溯）

### 改进

- 正文改为按块压缩存储，同规模书库的磁盘占用明显下降。
- 搜索范围明确为书名 / 作者 / 章节标题；驾驶舱展示压缩收益。

### 升级注意

- 首次启动会自动把存量正文重压一遍，大库耗时较长，迁移期间不监听端口；升级前先备份，
  迁移完成后建议 VACUUM 一次，否则文件不会变小。

## [0.1.0] - 2026-10-25 （据 git 历史回溯）

### 新增

- 导入本地 TXT：自动识别编码、清洗噪声、切分章节与卷，可重复导入而不产生重复书籍。
- 书架 / 详情 / 搜索 / 阅读器四类视图与手机首屏，阅读进度跨端聚合。
- 驾驶舱：库存、解析质量、导入趋势等图表接真实数据。
- 命令行入口：导入、启动服务、统计、重建索引、查看版本。
- 多架构 Docker 镜像与 compose 部署。

### 改进

- 解析正确性：书名清洗、超长单章再切、作者补捞、空壳章节、只有分卷的书按卷切章等缺陷归零。

### 升级注意

- 首版没有历史数据需要迁移；生产环境建议锁定精确版本号，不要跟 latest 裸跑。
